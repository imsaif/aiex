# OpenGraph Images

This directory contains OpenGraph (OG) images for social media sharing.

## Image Specifications

- **Dimensions**: 1200x630px (required by Facebook/Twitter)
- **Format**: PNG or JPG
- **File Size**: Keep under 1MB for optimal loading
- **Aspect Ratio**: 1.91:1

## Required Images

### 1. og-home.png
- Homepage/default OpenGraph image
- Should showcase the AI Design Patterns brand
- Include tagline like: "Discover AI UX Patterns" or similar

### 2. og-pattern-default.png
- Default image for pattern pages
- Generic AI design pattern visual
- Used when pattern doesn't have a specific thumbnail

### Optional: Category-specific images
- og-collaboration.png
- og-trustworthy.png
- og-natural-interaction.png
- og-performance.png
- etc.

## Design Guidelines

1. **Brand Consistency**: Use site colors and typography
2. **High Contrast**: Ensure text is readable at small sizes
3. **Clear Hierarchy**: Main message should be immediately visible
4. **Professional**: Maintain quality that represents the brand
5. **Mobile Preview**: Remember images appear small on mobile devices

## Creating Images

You can use tools like:
- Figma (recommended)
- Canva
- Adobe Photoshop
- Online OG image generators

## Testing

Test how your OG images appear using:
- [Facebook Sharing Debugger](https://developers.facebook.com/tools/debug/)
- [Twitter Card Validator](https://cards-dev.twitter.com/validator)
- [LinkedIn Post Inspector](https://www.linkedin.com/post-inspector/)
